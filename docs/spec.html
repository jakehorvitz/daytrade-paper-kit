Spec: Day-trading AI starter kit (paper only)

Stage 3 artifact. Derived from docs/interrogation.md revision 2 (score 96/100). Revised draft — awaiting Jake's Stage 3 sign-off. Every later stage is held to the version he signs.

Scope (v1)

  • Python 3.11+ package src/daytrade/, pytest suite, offline by default.
  • Deterministic SMA-crossover baseline strategy.
  • Paper-only simulated broker. Alpaca paper adapter stub with hardcoded paper base URL.
  • Risk manager: position cap, daily loss cap, persisted kill switch.
  • Backtester: next-open fills, slippage default 5 bps, commission 0, final 20% holdout, buy-and-hold benchmark, and an equity curve.
  • Optional LLM signal adapter, off by default, schema-validated, and not recommended by default.
  • docs/WORKFLOW.md: how Justin runs the Bones pipeline on this repo.

Confirmed decisions

  • Broker: Alpaca paper. The adapter uses only the hardcoded paper endpoint.
  • Priority order: safety, then speed, then simplicity. This supersedes the Stage 1 priority paragraph; docs/interrogation.md remains a pinned historical record and is not edited.

Non-goals

  • Any live-trading code path. None exists in v1.
  • Real-money brokers, real-time feeds, options or futures, web UI.
  • Profitability claims or investment advice.
  • Keys, personal data, Jake's memory, brains, or owner keys in the repo or the gift package.

Acceptance checklist

  1. AC-01 CSV input requires timestamp,open,high,low,close,volume. The loader rejects missing columns; nonnumeric or nonfinite OHLC/volume values; OHLC values that are zero or negative; negative volume; high < low; open or close outside [low, high]; duplicate timestamps; and non-monotonic timestamps. Every rejection reports the row and field/rule and has a test.
  2. AC-02 A timestamp must be ISO 8601 with an explicit timezone (Z allowed). The loader converts aware offsets to UTC and rejects malformed or timezone-naive values; duplicate and monotonic checks occur after normalization. Loaded timestamps are UTC. Prices are documented as unadjusted.
  3. AC-03 SMA-crossover baseline is deterministic: the same input gives the same signals.
  4. AC-04 Risk manager enforces the position cap as a fraction of current equity, counting pending orders.
  5. AC-05 Daily loss is realized plus unrealized loss against start-of-day equity, with the trading day in America/New_York.
  6. AC-06 Kill switch persists to .daytrade/kill_switch.json, blocks all orders once tripped, and survives a restart. It clears only manually.
  7. AC-07 Alpaca broker base URL is hardcoded to the paper endpoint. Constructing it with any other URL raises before any network call (test asserts no socket opened). No live-mode flag or env override exists.
  8. AC-08 Backtester fills actionable signals only at the next bar's open, applies 5 bps slippage and 0 commission by default, and writes those cost settings to reports/summary.json. A final-bar signal has no fill; open positions are marked to the final close net of existing fill costs. It writes reports/equity_curve.csv with a UTC timestamp and account equity for every evaluated bar.
  9. AC-09 For N bars, the chronological holdout is the final k = ceil(0.2*N) bars. It requires at least two holdout bars and a pre-holdout prefix of at least slow_window + 1 bars; otherwise the backtest fails with a clear error. Prior bars may warm indicators only; no tuning uses holdout bars. The holdout uses a fresh paper account and the same starting equity, risk, and cost settings for baseline, LLM (when enabled), and buy-and-hold comparisons. Summary reports holdout and buy-and-hold return metrics on the same bars.
  10. AC-10 LLM adapter is off by default. It accepts only strict JSON with action equal to buy, sell, or hold; confidence a finite numeric (not boolean) in [0,1]; and reason a string. Schema/type failure or a 10 s timeout yields hold through the risk manager. Raw responses are logged to reports/llm_log.jsonl; the adapter cannot bypass risk. When enabled, the summary reports LLM and baseline holdout net total return side by side and beats_baseline is true only for strict > (ties fail). Documentation may recommend LLM only with comparable non-synthetic holdout evidence that passes this test; v1 labels it unvalidated and makes no default recommendation.
  11. AC-11 python3 -m pytest -q passes. python3 -m daytrade.backtest examples/sample.csv exits 0 and writes reports/summary.json and reports/equity_curve.csv.
  12. AC-12 examples/sample.csv is generated deterministically (seed 7, synthetic, not market data). Sample config includes max_position_pct: 0.10 and max_daily_loss_pct: 0.02.
  13. AC-13 Every run prints the disclaimer: paper-only, no profitability claim.
  14. AC-14 docs/WORKFLOW.md and README.md exist. README states paper-only and no investment advice.
